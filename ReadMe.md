# HDLBits – Verilog HDL Solutions

A collection of my solutions to [HDLBits](https://hdlbits.01xz.net/wiki/Main_Page) exercises, focusing on **digital logic design and hardware description using Verilog HDL**.

This repository documents my practice and progress in developing hardware design skills, covering topics such as combinational and sequential logic, finite state machines (FSMs), counters, registers, and digital circuits.

The goal is to strengthen my understanding of **RTL design, digital systems, and FPGA development**, while improving my proficiency in Verilog through practical exercises.

Each solution is organized according to the HDLBits problem categories.
